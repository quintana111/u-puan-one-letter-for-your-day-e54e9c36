# One Letter for Your Day — Z

This entry is exactly one letter: **Z**, standing for the hidden word **"zero sleep"**. The letter was chosen because Z is itself the universal symbol of sleep — the "Zzz" of cartoons and comics — so pairing it with *zero* sleep turns the letter against its own meaning. That contradiction is what makes it land: it is vivid (everyone can picture the Zzz that never came), funny (the sleep letter admitting defeat), and true (a day run on no sleep is a day everyone recognises). Against blander letters it wins head-to-head because the letter and the word fight each other, and the joke is visible before a single extra word is said.
